Write a handoff document for another agent taking over this work. Requirements:
- What the task was and its current state
- What was tried, what worked, what failed (with file paths)
- What remains, in order
- Explicitly do NOT bias the successor toward my current solution - state it neutrally as "one approach that was attempted", and note where I was uncertain

Save to `HANDOFF.md` in the repo root unless told otherwise.
